TARGET AUDIENCE

Who is BitScribe For?

Different libraries require different parameters. BitScribe scales perfectly across your catalog's specific niches.

The Plex / Server Admin

Eliminate CPU-heavy server transcoding. Filter streams lacking optimized video/audio headers and ensure compatible stereo/surround codecs run direct-play natively on cellular clients, smart televisions, and mobile tablets.

The Media Archivist

Track media file preservation health. Identify corrupted headers or incomplete folders. Flag bitrate starvation zones to source reliable transcodes or high-fidelity encodes for pristine long-term storage backups.

The Music Collector

Locate compressed or duplicate track audio signatures. Scan structures to pinpoint redundant album duplicates, tag lossless formats with high-fidelity properties, and track down starved files to protect the library sound profile.

DOCUMENTATION HUB

Full Core Scan Tutorials

Step-by-step guides, precise reference models, and frequently asked questions for the ultimate home lab curator.

1. Streaming Compatibility Scan

Best for optimizing direct play & eliminating CPU-heavy server transcoding.

  1. Open the Options tab and check Streaming Compatibility Scan.
  2. Toggle either Modern Standards (ideal for Apple TV 4K, Shield) or Legacy Standards (ideal for mobile remote streams).
  3. Choose accepted video codecs (HEVC, H264) and select audio capabilities (AC3, EAC3).
  4. Run a scan to monitor direct play ratios and locate transcode-heavy properties.

2. Discovery & Cataloging Mode

Zero-friction library inventorying bypassing compatibility criteria.

  1. Enable Discovery Mode under settings to disable direct-play check rules.
  2. Apply optimized filters like Video Only, Music Only, or Corruption Scan.
  3. Select your checklist parameters (codecs, containers, high-fidelity HDR profiles).
  4. Items using rare formats are tracked as "Discovery Skip/Unresolved" for manual analysis.

3. Media Duplication Audit

Tracks separate film-resolution and audio-codec duplicates to reclaim storage.

  1. Toggle the general duplication check or select separate Video or Music toggles.
  2. Video: Normalizes release tags and directories. Groups files matching within a 3-minute duration window (e.g. 1080p and 4K pairs).
  3. Music: Matches track titles & artists, checking metadata logs with a 30-second duration gate.
  4. Review the warnings tab to safely delete redundancies, favoring high-fidelity lossless files.

4. Quality Anomaly Detection

Flags bloated lossless tracks and aggressively compressed starved streams.

  1. Turn on Quality Anomaly Detection inside your Options rules.
  2. Bloated Files: Highlights media files consuming extreme bitrates (e.g. 1080p transcodes exceeding 30 Mbps).
  3. Starved Files: Pins down overly compressed video streams below acceptable benchmarks (e.g. 1080p under 1.5 Mbps).
  4. Identifies under-bitrate FLAC/audio tracks evaluated under 160 kbps thresholds, helping you target files to upgrade.

5. Subtitle Completeness Audit

Audits files missing embedded or adjacent external companion subtitle tracks.

  1. Check the Subtitle Completeness Audit checkbox on the Options page.
  2. The system analyzes your files for internal subtitle tracks and queries adjacent companion paths for .srt companion files.
  3. The dashboard replaces the music codecs card with a real-time **embedded subtitle presence index**.
  4. Flags files lacking subtitle coverage so you can ensure accessibility for remote family of users.

Scan Reference Guide

Comprehensive reference list of specifications, bounds, and rules for each engine.

Streaming Compatibility Scan

Analyzes client stream bounds. Modern mode accepted formats include HEVC, H.264, and AV1, combined with discrete surround codecs (AC3, EAC3, TrueHD). Legacy restricts video purely to H.264 Only, ensuring older targets stream directly without CPU penalties.

Discovery & Cataloging Mode

Indiscriminately inventories paths. Allows power users to specify custom checklists for up to 18 video formats, 15 discrete surround encoders, 12 stereo configurations, and 16 target container formats (MKV, MP4, FLAC). Excellent for exporting flat datasets across all parameters.

Media Duplication Audit

Heuristics-driven deduplication engine. Movie parsing filters release naming keywords (e.g. REPACK, Criterion) and merges items within a 3-minute playtime limit. Music checks read ID3 tags, grouping matching titles + artists within a tight 30-second duration boundary.

Quality Anomaly Detection

Flags compression waste. "Bloated" matches include files whose resolution-to-bitrate ratio exceeds 30 Mbps on standard 1080p transcodes, or uncompressed multi-channel WAV formats on raw imports. "Starved" alerts trigger for videos compressed below 1.5 Mbps, resulting in muddy, pixelated tracks.

Frequently Asked Questions (FAQ)

Quick queries regarding catalog indexes, audio starvation thresholds, and duplication heuristics.

Q: How are duplicate videos matched with different release names?

The deduplication engine normalizes filenames by removing common release keywords, scene tags (e.g. REPACK, x265, HDR), and years. It then groups matching titles whose durations fall within a 3-minute window to avoid false positives.

Q: What causes an audio stream to be flagged as "Bloated"?

Lossless stereo formats (like FLAC) with bitrates exceeding 3000 kbps, or uncompressed raw multi-channel WAV files where compressed formats would yield identical auditory fidelity, are flagged as bloated to save disk space.

Q: What does the 'Discovery Skip / Unresolved' count refer to?

In Discovery Mode, files using rare custom formats or codecs excluded from your active settings configurations checklists are skipped from the index rather than computed as active so the sysadmin can review them safely.

Q: Can I customize the transcode alerts thresholds?

Yes. All accepted codec checklists, maximum/minimum bitrate ranges, container exclusions, and subtitle settings folders can be updated directly within the live Rules Configurator under the Options page tab.
