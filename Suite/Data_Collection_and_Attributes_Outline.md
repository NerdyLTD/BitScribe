# BitScribe Digital Library Steward - Data Collection and Attributes Outline

This document provides a highly structured, comprehensive outline of all data types, files, parameters, and attributes parsed, logged, and organized by the **BitScribe Digital Library Steward** scanning pipeline. 

BitScribe operates under a strict **Zero-Telemetry, Offline-First Privacy Policy**. Every attribute listed below is extracted locally from the media file headers using a native `ffprobe` wrapper and stored entirely inside your local sandbox filesystem (`./BitScribeDB` SQLite database). No personal metrics, paths, or filenames are ever transmitted to external web services.

---

## 1. High-Level Category Hierarchy

BitScribe automatically catalogs items into one of the following category models based on folder path signatures within your configured `MediaRoot`:

### A. Video Classifications
*   **Movies:** Full-length theatrical movies.
*   **TV:** Episodic television show contents.
*   **Series:** Chronological shows and standard multi-episode series.
*   **Documentaries:** Real-world informational films.
*   **DocuSeries:** Multi-part episodic documentary series.
*   **Plays:** Recorded theatrical performances and stage musicals.
*   **Specials:** Television specials, comedy standups, or single-broadcast releases.
*   **Shorts / Short Films:** Short duration narratives (typically under 40 minutes).
*   **Extras:** Bonus features, featurettes, interviews, trailers, and deleted scenes.
*   **Music Videos:** Audio-visual musical performances.

### B. Audio/Music Classifications
*   **By Artist:** Music organized under structured Studio Albums, Singles, or EP directories.
*   **Soundtracks:** Music collections mapped to specific Movies, Shows, or Games.
*   **Compilations:** Multi-artist compilation projects.
*   **Concerts:** High-fidelity live musical sets or stadium recording audio tracks.

## 3. Nested Complex Data Structures

Several properties contain complex nested streams parsed from containers that house multiple audio languages, multi-track mixes, or soft/hard subtitle maps.

### A. Audio Streams Array (`AudioTrack[]`)
Multiplexed containers frequently house multiple audio configurations. BitScribe indexes every single audio stream available:

*   **`index` (INTEGER):** The sequence index of the stream in the multiplex (e.g., `1`, `2`).
*   **`codec` (TEXT):** Format of the audio encode (e.g., `"truehd"`, `"eac3"`, `"ac3"`, `"aac"`, `"dts"`, `"flac"`, `"mp3"`, `"opus"`).
*   **`channels` (INTEGER):** Discrete layout channel count (e.g., `1` for Mono, `2` for Stereo, `6` for 5.1 Surround, `8` for 7.1 Surround).
*   **`language` (TEXT):** ISO 3-letter language descriptor parsed from stream tags (e.g., `"ENG"`, `"SPA"`, `"FRA"`, `"JPN"`).
*   **`title` (TEXT):** Custom text metadata label assigned to the track (e.g., `"Director's Commentary"`, `"Descriptive Audio"`).

### B. Subtitle Streams Array (`SubtitleTrack[]`)
BitScribe audits container subtitle characteristics to flag transcoding risks (image-based subtitles like PGS are highly resource-intensive compared to text-based SRT):

*   **`index` (INTEGER):** The sequence index of the subtitle stream (e.g., `3`, `4`).
*   **`codec` (TEXT):** Format of the subtitle layout (e.g., `"srt"`, `"subrip"`, `"ass"`, `"hdmv_pgs_subtitle"` (PGS), `"dvd_subtitle"` (VOBSub), `"mov_text"`).
*   **`language` (TEXT):** ISO 3-letter descriptor of the subtitle track (e.g., `"ENG"`, `"GER"`).
*   **`title` (TEXT):** Custom subtitle stream metadata label (e.g., `"English (SDH)"`, `"Forced Narrative"`).
*   **`forced` (BOOLEAN):** Flag identifying forced track behavior (which overrides default subtitle states for translation scenes).
*   **`isExternal` (BOOLEAN):** True if this is an external companion sidecar file (e.g., `.srt`, `.ass` adjacent on disk), false if embedded.

## 4. Metadata Tags Collection (`tags`)

For music assets and specific video formats supporting extensive container tag headers (ID3v1, ID3v2, Vorbis Comments, MP4 tags), BitScribe captures additional key-value text maps:

*   **`artist` / `album_artist`:** Creator or performing entity.
*   **`album`:** Parent collection title containing the current track.
*   **`title` / `song_title`:** Target asset name or track title.
*   **`track`:** Track number sequence inside the album (e.g., `"01"`, `"05"`).
*   **`disc`:** Disc index inside multi-part boxsets.
*   **`genre`:** Content genre classification tags.
*   **`composer`:** Score composer credit metadata.
*   **`encoder` / `tool`:** Software or encoder package utilized to assemble the binary asset.

## 5. Summary Metrics and Pipeline Flag Logic

Using the compiled item attributes, BitScribe triggers downstream streaming audit ratings:

1.  **Direct Play - Bleeding Edge (`level = 'bleeding'`):**
    *   Triggered by: `videoCodec` is `av1` / `vvc` / `vp9` OR primary `audioCodec` is `truehd` / `dtshd` / `flac` / `pcm`.
2.  **Direct Play - Modern (`level = 'modern'`):**
    *   Triggered by: `videoCodec` is `hevc` or `h264`, `videoBitDepth` matches `8-bit` or `10-bit`, `audioCodec` is `eac3`, `ac3`, or `aac`.
3.  **Direct Play - Legacy (`level = 'legacy'`):**
    *   Triggered by: `videoCodec` is `h264`, `videoBitDepth` is `8-bit`, `audioCodec` is `aac` or `mp3` stereo.
4.  **Transcode Required (`level = 'unfriendly'`):**
    *   Triggered by: Outdated codecs (DivX, Xvid, WMV), outdated container formats (`avi`), or image-based subtitles with active rendering flags.
5.  **Corrupted (`level = 'corrupted'`):**
    *   Triggered by: Any file where the offline `ffprobe` wrapper fails to return structural stream headers, or reports physical header offsets as zero bytes.
