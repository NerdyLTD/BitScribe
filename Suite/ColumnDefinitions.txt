# BitScribe Digital Library Steward - Excel Column Definitions

This reference documents the purpose and output of each column generated by the Stream Audit Excel exporter.

- Missing Metadata: Lists the tags identified as missing during the metadata audit (e.g. "Release Year", "Director", "Actor"). Returns "None" if all evaluated tags are present.
- Stream Friendly?: Provides the compatibility rating of each asset for network streaming. Values include:
  - Bleeding Edge: High-efficiency modern encode. Directly plays on Bleeding Edge environments. Highlighted in Red.
  - Modern+: Native support on modern hardware. Highlighted in Green.
  - Legacy+: Native support on legacy hardware, compatible with modern hardware. Highlighted in Yellow.
  - Transcode Required: Requires server-side transcoding hardware format conversion to play smoothly.
- File Name: The basename of the file on disk.
- Container: The multimedia container format (e.g., MKV, MP4, M4V, FLAC). 
- Video Codec: The encoded video format (e.g., AV1, HEVC, H264).
- Resolution: The detected video scaling and explicit dimensional footprint (e.g., "1080p (1920x1080)").
- Audio Tracks: The total distinct count of audio streams multiplexed into the asset container.
- Audio Codecs: A comma-separated list characterizing each distinct audio stream's encoding.
- Subtitles: A comma-separated list defining each embedded subtitle format.
- Series Title: The parent show name parsed from the filename or embedded metadata (for episoded content).
- Season: The parsed chronological season assignment (for episoded content). 
- Episode: The parsed chronological episode assignment (for episoded content).
- Episode Title: The individual embedded episode title tag, if present.
- Title: The distinct release title (for movies) or absolute title.
- Release Year: The 4-digit temporal release assignment tag or filename parser output.
- Artist: The creator or performer (primarily for Music categories).
- Album Title: The collection assignment tag (primarily for Music categories).
- Song Title: The explicit track name metadata tag.
- File Format/Codec: The container mapped for non-video playback (typically Music audio codecs).
- Video Bitrate: The measured throughput required to push the video payload across the network in Mbps.
- Audio Bitrate: The measured throughput required to decode the audio payload in kbps.
- Poster: The status of artwork detection ("Embedded" inside the container, "External" on adjacent disk paths, or "Missing").
- Corruption Type: Specifies any structural container error states or logical unreadability.
- Recommendation: Contextual advisory provided by the scanner pipeline for the current file format.
- Analysis Notes: Telemetry tracing provided by the stream audit runtime for debugging issues.
- File Path: The absolute canonical pathway to the asset on the underlying host disk.
