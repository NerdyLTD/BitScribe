# BitScribe RX - File Renamer Feature & Architecture Specification

## Overview
The **File Renamer** is the foundational active remediation tool within **BitScribe RX**. Built to consume the audit database generated by **BitScribe Steward**, it safely renames media files across movie, documentary, short, and episodic TV collections using standard presets or flexible user-defined pattern templates.

---

## 1. Presets & Categorization

### Movie & Single-Item Video Presets
Designed for standalone video items (Movies, Documentaries, Stand-up Specials, Shorts):
- **Simple / Standard Preset**: `Movie Title (YEAR).ext` *(e.g., Inception (2010).mkv)*
- **Detailed Media Preset**: `Movie Title (YEAR) [1080p HEVC AAC].ext`
- **Customizable Single-Item Templates**: Support for special classifiers like `[Special]`, `[Doc]`, or `[Short]`.

### TV Series & Episodic Presets
Designed for multi-episode series, season blocks, and miniseries:
- **Standard Episodic Preset**: `Show Name - S01E02 - Episode Title.mp4`
- **Compact / Initials Preset**: `BtVS S01E02.mp4`
  - *Automatic Initials Generation*: Show initials (e.g., `BtVS` for *Buffy the Vampire Slayer*) are dynamically derived from the show's root directory name or database entry.
- **Season/Episode Format Dropdown**:
  - `S01E02` (Standard padding)
  - `1x02` (Classic format)
  - `s1e2` (Minimalist format)
  - `S01.E02` (Dot separator)

---

## 2. Custom Naming Scheme Engine & Tag Tokens

Users can construct custom target patterns using a dropdown token picker and format builder:

### Text & Metadata Tokens
- `{Title}` / `{CleanTitle}`: Matched or parsed title.
- `{Initials}`: First letters of major words in the title or parent directory.
- `{Year}` / `{Date}`: Release year.
- `{Season}` / `{Episode}`: Season and episode numbers (with configurable zero-padding).
- `{EpTitle}`: Name of the individual episode.
- `{VideoCodec}` / `{Codec}`: e.g., `H.264`, `HEVC`, `AV1`.
- `{Resolution}` / `{Res}`: e.g., `1080p`, `4K`, `720p`.
- `{AudioCodec}`: e.g., `AAC`, `AC3`, `FLAC`, `TrueHD`.
- `{AudioChannels}` / `{Channels}`: e.g., `2.0`, `5.1`, `7.1`.
- `{BitDepth}`: e.g., `8-bit`, `10-bit`.
- `{ReleaseGroup}`: e.g., `CtrlHD`, `NTb`.

### Formatting & Article Controls
- **Article Options**: Lowercase, move to end, or strip leading articles (`The`, `A`, `An`).
- **Case Styling Dropdown**: Title Case, Clean Case, Lowercase, Uppercase.
- **Delimiter Options**: Spaces (` `), Dots (`.`), Dashes (`-`), Underscores (`_`).

---

## 3. Flexible Multi-Modal Selection Hierarchy

The UI allows flexible selection of files to process:
1. **Individual File Selection**: Manual checkboxes for fine-grained file-by-file control.
2. **Physical Directory Selection**: Folder tree picker targeting all files within a physical directory path (e.g., `D:\Downloads\Unsorted_TV`).
3. **Logical Library Selection**: Grouped selection by catalog entities (e.g., whole TV Series, specific Season blocks, or Movie collections).

---

## 4. Native Engine & System Architecture

- **Custom TypeScript + Rust Native Engine**: Built in-house using pure TypeScript logic for pattern parsing and Tauri Rust system calls for filesystem execution. Avoids external CLI dependencies or fragile, non-portable OS shell scripts.
- **In-Memory Instant Live Diffing**: Pre-views proposed changes side-by-side (`Original Name` -> `Proposed Name`) in memory instantly before performing any disk operations.

---

## 5. Safety, Validation & Operational Safeguards

- **Pre-Flight Validation & Collision Detection**: Scans for duplicate destination paths or existing files before execution, blocking accidental overwrites.
- **Cross-Platform Character Sanitization**: Strips or replaces illegal OS filesystem characters (`/ \ : * ? " < > |`) safely.
- **Atomic Two-Step Case-Only Renaming**: On case-insensitive filesystems (Windows NTFS, macOS APFS), case-only updates (e.g., `file.mkv` -> `FILE.mkv`) execute via a temporary intermediate file (`file.mkv` -> `file.mkv.tmp` -> `FILE.mkv`).
- **Transaction History & Soft Undo**: Logged transaction history (`.rename_history` in SQLite/JSON) allowing one-click restoration/rollback of renamed files.
- **Confidence Scoring & Dry-Run Mode**: Flags items with missing tokens or ambiguous metadata (High / Medium / Low confidence) and allows complete dry-run simulations.
- **Sidecar File Auto-Tracking**: Automatically renames matching companion files (`.srt`, `.ass`, `.nfo`, `.poster.jpg`) alongside primary media files.
