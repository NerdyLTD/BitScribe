Five Pillars of Library Stewardship

BitScribe runs robust analytical engines to keep your library pristine, providing actionable insights instantly.

1. Media Discovery

Scans your entire library into the database. Essential starting point to catalog movies, TV shows, and music. Identifies rare or unrecognized codecs automatically.

2. Stream Audit Scan

Evaluates media files against standard playback constraints. Identifies files that require transcoding for seamless playback on modern network streamers or legacy devices.

3. Subtitle Audit

Identifies missing subtitles and classifies formats (SRT, PGS, VOB). This data is critical for evaluating streaming compatibility and identifying potential high-CPU server transcodes.

4. Duplication Audit

Detects identical or closely related media files saving terabytes of disk space. Analyzes video runtimes, music ID3 tags, and codecs to safely flag duplicate assets.

5. Quality Audit

Detects corrupted files, bloated bitrates, and resolution anomalies. Ensures you aren't wasting space on unnecessarily large files or keeping unwatchable, corrupted media.

The Story Behind BitScribe

BitScribe isn't just an application; it's a testament to the future of collaborative software development. Designed, engineered, and built entirely through a partnership between a human creator and an AI agent, it demonstrates what's possible when human vision meets autonomous execution.

Together, we have invested well over 200 combined hours of dedication across 11 consecutive versions—from a tiny experimental command line script (v0.1) into this production-grade, highly-optimized full-stack management dashboard.

The human half of the team provided a comprehensive vision, direction, usability standards, extensive technical experience, and hours of hands-on testing and refining of both functionality and user experience. The AI half of the team built complex analytics engines, database integrations, and responsive UI components. BitScribe represents a beautiful milestone in how humans and AI can cooperate to rapidly engineer solutions neither could have done alone.

Video Duplication strips release keywords/years and matches films within a 3-minute playtime limit.

Music Duplication parses ID3 Metadata (Title + Artist) and checks file lengths within a tighter 30-second window, flagging duplicates and favoring FLAC and 320Kbps MP3 files for music. MP3s with bitrates lower than 320Kbps will be flagged.

Files are flagged as unfriendly if they use mismatched codecs, old codecs that aren't designed for streaming (like DivX or Xvid), unoptimized containers (like AVI), or potentially the newest "bleeding edge" codecs that are not yet well supported in consumer hardware. These issues force your media server to transcode the video on the fly, which can cause playback buffering and high server CPU usage.

As long as some parent folder contains a matching category keyword (like Movies, Films, etc., even if it is nested like movies/a/MovieTitle/MovieName.mkv), it is automatically identified as a movie. The scanner parses this flawlessly! When a folder path matches "Extras" (or specials, bonus features, deleted scenes, behind-the-scenes, etc.), BitScribe recursively climbs the folder tree to skip any season folders (e.g. Season 01), correctly identifying the parent TV Show or DocuSeries title as the main group name.

BitScribe matches folder names using flexible keyword checks (case-insensitive):

  • Movies: Movies, Movie, Films, Film, Cinema, Cinemas, UHD, Foreign
  • TV Shows: TV Shows, TV Show, TV, Series, Shows, Cartoons, Anime
  • DocuSeries: DocuSeries, Documentary Series, Documentary Show
  • Documentaries: Documentaries, Documentary, Docs, Doc
  • Shorts: Shorts, Short films, Short film, Shortfilms
  • Concerts: Concerts, Concert, Live Shows, Live Show, Live Performances, Live Performance
  • Music: Music, Audio, Soundtracks, Compilations

If a folder path doesn't contain any recognizable keyword, files default to Other, unless the filename has explicit TV formats (like `S01E01`) or Years (like `(1999)`), which enables smart auto-classification fallback.

BitScribe handles this beautifully! Many media managers use a dedicated top-level folder called Specials for seasonal gems or holiday one-offs.

  • - Smart Detection: When Specials is scanned as a top-level parent folder, BitScribe bypasses the generic "Extras" tag and intelligently groups these one-offs under the Movies category (if they have a release year or default to standalones) or under TV Shows (if filename contains episode templates like S00E01).
  • - Nesting Extras: Behind-the-scenes "Extras" subfolders placed inside individual show or movie folders (e.g., TV Shows/Breaking Bad/Specials/) are still correctly identified as native companion Extras!
